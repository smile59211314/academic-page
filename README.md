# Zifeng Gong — Academic Homepage

Jekyll-based academic homepage for Zifeng Gong, built with the information architecture of [academic-homepage](https://github.com/luost26/academic-homepage) and personalized with ORCID record data and a studio portrait.

## Local preview

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open `http://localhost:4000/academic-page/`.

## GitHub Pages

Push the repository's `main` branch and the included GitHub Actions workflow builds and deploys the site to GitHub Pages. The expected repository is `smile59211314/academic-page`.
